# Multi-alphabet v8 — historical alternative

This snapshot preserves the earlier four-alphabet firmware and its [original guide](GUIDE.md). It defaults to standard Colemak and has different thumb roles, modifier order, keys and chords from the current root Miryoku layout. Treat it as reference or a separate experiment, not the active configuration.

This folder is not built by the root workflow. For a separate build, copy this folder's source into a standalone configuration workspace, use its `config/west.yml` and custom ZMK module, and rebuild both halves. It has not been retested since being archived here. Check matrix wiring and hardware before flashing.
